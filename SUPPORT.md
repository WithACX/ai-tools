# Support

## Report a bug

Report a bug with the
[bug report form](https://github.com/withACX/ai-tools/issues/new/choose). The
form asks for the app, the skill and its version, the steps taken and what
happened.

A-CX reads every report but promises no response time and no fix. A report with
exact steps is the one most likely to get fixed.

## Report a vulnerability

Never report a security problem in a public issue. [SECURITY.md](SECURITY.md)
explains how to report it privately.

## Code contributions

A-CX does not accept code contributions to this repository. A pull request from
outside A-CX is closed with a pointer to the bug report form. Report the problem
or the idea as an issue instead.

## Contact A-CX

For anything else, contact A-CX through [www.a-cx.com](https://www.a-cx.com).
