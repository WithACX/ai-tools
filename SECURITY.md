# Security

## Report a vulnerability

Report a vulnerability in a skill privately, through GitHub private
vulnerability reporting on this repository. Never report it in a public issue,
where anyone could read it before a fix is out.

1. Open the **Security** tab of this repository.
2. Select **Report a vulnerability**.
3. Describe the problem, the skill and its version, and the steps that show it.
4. Select **Submit report**.

Only A-CX and the reporter can read a private report. GitHub explains the steps
in
[Privately reporting a security vulnerability](https://docs.github.com/en/code-security/how-tos/report-and-fix-vulnerabilities/report-privately).

## What to expect

A-CX reviews every private report and fixes a confirmed vulnerability in a new
release. [CHANGELOG.md](CHANGELOG.md) lists each release.
