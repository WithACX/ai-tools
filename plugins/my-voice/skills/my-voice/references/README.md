# my-voice references

Detail the my-voice `SKILL.md` loads at the step that needs it, so the skill
body stays a short workflow. Storage and format are kept in separate files on
purpose: where the profile lives may change between releases without the
format changing, and the reverse.

Conventions:

- The check script's `--contract` owns every machine-checked value of the
  format; these files explain meaning and procedure and cite it.
- Nothing here names an organization or carries an organization's rules. Those
  arrive only through an overlay file the plugin bundle may carry.
- Examples use synthetic people and example.com addresses, never a real
  person's writing.
