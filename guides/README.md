# Install guides

Each guide covers one app: what to turn on first, how to install a skill from
AI Tools, how to update and remove it, and what to do when a step fails. Pick
the guide for the app in use.

| App | Where it runs | How skills arrive | Guide |
|---|---|---|---|
| Claude.ai | The web, and chat in the Claude desktop app | Upload a skill ZIP from the latest release | [claude-ai.md](claude-ai.md) |
| Claude Code | The terminal | Add the marketplace with one command | [claude-code.md](claude-code.md) |
| Cowork | The Claude desktop app | Add the marketplace, or upload a skill ZIP | [cowork.md](cowork.md) |
| Codex | Codex CLI, and Codex in the ChatGPT desktop app | Add the marketplace with one command | [codex.md](codex.md) |
| ChatGPT | The web and the ChatGPT desktop app | The channels OpenAI offers for the plan | [chatgpt.md](chatgpt.md) |

## Which apps a skill works in

A guide explains how to install in an app. The skills table in the
[main README](../README.md) lists an app for a skill only after that skill passes
verification in that app for the release. When an app is missing from a skill's
row, that skill has not been verified there yet.
